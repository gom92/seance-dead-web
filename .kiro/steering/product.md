# Steering — Product

## What Séance is
A séance table for the dead web. The product's job is emotional before it
is technical: make visiting a dead website feel like a small ritual, not a
database query. Every word on the page should sound like a medium, not a
manual — "summon", "ghost", "autopsy", "apparition", "obituary".

## Who it is for
Anyone who ever typed a beloved old URL and got nothing back. Nostalgia is
the audience; the demo should make a judge feel something in 30 seconds.
GeoCities is the canonical first summon: everyone recognises it.

## Non-negotiables
- **Honest verdicts.** Never claim a site is dead when we only failed to
  reach it. Three states only: alive, dead, unknown — with the reason
  visible.
- **No accounts, no tracking, no backend.** The app must work as static
  files. If a feature needs a server, it does not ship.
- **Free data only.** The Internet Archive's public APIs are the only
  dependency. No API keys anywhere in the repo.
- **Respect the dead.** Archived pages belong to the Archive and the
  original sites. Link back; never re-host content as our own.
